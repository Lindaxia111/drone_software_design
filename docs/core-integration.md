# v0.2 核心整合与交互补全

参考来源：`1/dronedesign_platform/drone_platform/dronedesign/`。保留参考目录原始源码，选择物理、契约、参数工具、评估器和优化器整合到 `apps/backend/dronedesign/`。

## 保留现有持久化架构

继续使用 FastAPI、React、SQLite 和独立 Worker。没有替换为参考工程内存态 Orchestrator。`core_adapter.py` 负责把应用快照转换为参考核心不可变 IR 和测试场景，再将结果转换回应用契约。

L1 接入部件质量/重心、平行轴惯量合成、控制分配矩阵求秩、有界悬停配平、功耗和桨盘间距检查。L2 接入 6-DOF 刚体积分、一阶电机、级联位置/姿态/速率环、风场、故障与随机化。报告明确区分 ANALYTIC、DEMO、DYNAMICS 和尚未评估的 PENDING。

进化搜索复用参考 (μ+λ) 策略。每代从持久化完成结果重建优化器，当前代提案仅作内存加速；进程重启不依赖 pickle。种子投影到搜索范围，固定边界作为固定参数处理，不同实验的内存批次按 run_id 隔离。原随机搜索和历史演示请求保持可读。

## 核心修正

- 随机化试验只要任一失稳，整体不再错误通过。
- 同一旋翼多次故障不能在后续循环中被较轻故障恢复。
- 随机化使用实验 seed，缓存仍包含完整场景、种子和评估器版本。
- 轨迹初始帧为 t=0，积分后帧使用更新后的真实时间；帧数约束在 601 帧以内。
- 物理参数解析输出包含名义质量、合成重心、完整惯量与实际控制增益。
- 进化种子被登记为可选父代，避免第一代优质基准被忽略。
- L2 墙钟截止受实验剩余时间限制，最多 30 秒；TIMEOUT/CRASHED 不入缓存。
- 新增步长、积分步数、故障目标与控制参数校验，拒绝当前动力学控制器不支持的推力轴。

## 暂停与查看参数

顶部控制入口始终保留。完成后暂停禁用并解释原因；“重新测试”创建新实验，不修改原记录。暂停保证不再派发新任务，当前评估允许完成归档。

选择新建实验时不再清空已返回的实验状态；轮询请求带本地操作序号，防止旧响应覆盖暂停/恢复后的状态。“创建后暂不启动”允许先检查配置。

新增候选详情 API：`GET /api/experiments/{run_id}/candidates/{candidate_id}`，按实验归属检查，返回原始构型、请求快照、逐级评估和执行尝试。前端支持结构化参数、运行增益、约束诊断、轨迹时间检查及完整 JSON。

## 兼容性与限制

历史请求缺少 evaluation_mode/optimizer 时仍按 demo/random 解释。没有删除实验、修改历史构型或清空数据库。评估器版本已升级，避免使用旧演示结果或缺少新增运行参数的缓存。

模型仍是探索级：惯量输入/估算、线性推力与阻力、固定效率、电池简化；领域随机化当前扰动机身质量和惯量。没有接入 L3、真实零件库、Parquet、分布式队列、Optuna/PyMOO 或 3D 场景渲染。
