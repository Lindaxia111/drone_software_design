# 分阶段开发与验收

## 阶段一：可复现工程闭环

已实现范围：核心契约、基准四旋翼、随机搜索、L1 简化评估、演示 L2、独立 API/Worker、预算预占、缓存、暂停恢复、取消、看板、方案比较与 JSON 导出。

验收目标：默认实验跑通；同种子可复现；重复输入命中缓存；恢复不丢候选进度；更换约束后正确重筛；预算不超支；执行错误不污染缓存。实际验证见 validation.md。

## 阶段二：可信 L1/L2 与优化算法（核心已接入，继续完善）

v0.2 已从参考工程整合质量/重心/惯量合成、控制分配与有界配平、6-DOF/级联 PID、风场/故障/随机化及进化搜索。已接入持久化恢复、参数详情和名义轨迹时间查看。

以下是阶段二的完整范围；其中进一步模型标定、Optuna/PyMOO、多场景联合聚合、Parquet/3D 回放和基础设施扩展仍待开发：

1. 组件质量、重心和完整惯量合成；升级 DroneIR。
2. 控制分配、限幅悬停配平及控制裕度。
3. 经基准验证的 6-DOF 模型、级联 PID、FRD/NED 适配。
4. 悬停、阶跃、航点、风扰、故障注入和领域随机化。
5. Optuna/PyMOO、自适应优化器检查点与多场景聚合。
6. 遥测、Parquet、时间轴与 3D 回放。
7. 按实际需求引入多进程、PostgreSQL、对象存储。

验收目标：物理模型通过解析/参考算例；相同设计和种子稳定复现；真实评估与 DEMO 隔离；优化效果经独立测试场景验证。
