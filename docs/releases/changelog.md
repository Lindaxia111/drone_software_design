# 变更记录

当前实现以 [工程架构](../architecture/overview.md) 为准；本页仅保留历史变化。

## v0.3.0 · 2026-11-25

- 统一跨视图选中和悬停状态，图表支持点选查参、缩放与位置调整。
- 帕累托卡片支持集合查看、2–3 个方案参数 Diff 和列表筛选。
- 接入懒加载的程序化 Three.js 构型，支持旋转、视角、拆解、桨叶动画与部件拾取。
- 新增对称/单轴参数编辑、静态指标与干涉提示、草稿重置和导出。
- 衍生候选保存父方案哈希，由 Worker 重评，按菱形联动回显；原记录保持不变。
- 保留预算、缓存和恢复语义，兼容既有数据库，并新增回归测试。

## 文档整理 · 2026-11-25

- 根 README 精简为项目简介、启动入口和文档导航。
- 使用、架构、开发、质量与版本内容按用途归类，增加统一索引与维护规则。
- 统一当前能力描述，删除混杂在架构说明中的旧版本状态。
- 核心物理和契约测试归入 `tests/core/`，根测试命令统一收集。
- 移除已完成整合的外部参考工程副本、压缩包、示例输出及初始设计 PDF；保留生产核心和有效测试。

## v0.2.0 · 2026-11-24

- 接入质量/重心与惯量合成、控制矩阵求秩、有界悬停配平及 6-DOF/PID。
- 支持风场、故障、机身参数随机化和 (μ+λ) 进化搜索。
- 进化策略通过持久化结果重建，运行参数记录合成惯量和实际增益。
- 任一随机试验失稳均判失败，重复故障不恢复已丢失推力，轨迹时间对应实际积分状态。
- 工作台补齐持续可见的暂停入口、初始暂停、复测、实验参数与候选详情。
- 保留演示模式和旧请求兼容性；评估器版本升级，防止错误缓存复用。

## v0.1.0 · 2026-11-24

- 建立参数化构型、随机搜索、简化 L1 和演示 L2 的软件闭环。
- 提供独立 API/Worker、SQLite、预算预占、缓存、暂停恢复与取消。
- 实现收敛/帕累托看板、候选简图和 JSON 导出。
