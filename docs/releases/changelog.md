## v0.2.0 · 2026-11-24

- 接入质量/重心与惯量合成、控制矩阵求秩、有界悬停配平及 6-DOF/PID。
- 支持风场、故障、机身参数随机化和 (μ+λ) 进化搜索。
- 进化策略通过持久化结果重建，运行参数记录合成惯量和实际增益。
- 任一随机试验失稳均判失败，重复故障不恢复已丢失推力，轨迹时间对应实际积分状态。
- 工作台补齐持续可见的暂停入口、初始暂停、复测、实验参数与候选详情。
- 保留演示模式和旧请求兼容性；评估器版本升级，防止错误缓存复用。

## v0.1.0 · 2026-11-24

- 建立参数化构型、随机搜索、简化 L1 和演示 L2 的软件闭环。
- 提供独立 API/Worker、SQLite、预算预占、缓存、暂停恢复与取消。
- 实现收敛/帕累托看板、候选简图和 JSON 导出。
