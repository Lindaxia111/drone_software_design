# 实验操作指南

流程：配置目标 → 生成候选 → 分层评估 → 比较方案 → 查看记录与导出。

## 创建实验

点击“新建实验”：

| 配置 | 含义 |
|---|---|
| 评估模式 | 动力学或快速演示，工作台默认动力学 |
| 寻优算法 | 进化搜索或随机搜索 |
| 目标与约束 | 默认比较续航和跟踪误差，限制质量与推重比 |
| 代数与每代数量 | 乘积决定候选数量上限 |
| L1/L2 预算 | 实际评估次数上限，缓存命中免费 |
| 随机种子 | 与设计和场景一起决定可复现结果 |
| 总时限 | 运行状态累计的墙钟时间上限 |
| 场景 | 任务、时长、步长、高度、风场和风速 |
| 鲁棒性测试 | 可选机身质量/惯量随机化和单旋翼失效 |
| 搜索范围 | 允许调整的物理参数上下界 |

“完整配置 JSON”支持种子构型、航点、多个故障和额外搜索参数。填写后以 JSON 为准，后端仍会校验。字段定义见 [请求契约](../../schemas/ExperimentRequest.schema.json)。

- **创建并运行**：进入计算队列。
- **创建后暂不启动**：保存为暂停状态，检查配置后启动。

## 运行控制

| 当前状态 | 可执行操作 |
|---|---|
| 等待 / 运行中 | 暂停、取消、查看、导出或新建复测 |
| 已暂停 | 启动 / 继续、取消、查看、复测 |
| 已完成 / 已取消 | 查看记录、导出、按原参数复测 |

暂停阻止新任务派发，已派发任务允许完成归档。继续保留候选序号和预算消耗。取消后该实验不可恢复，可以复测。

“已完成”表示编排结束，可能因为搜索完成、执行预算耗尽或时限达到上限。具体原因显示在流水线下方，不表示全部候选合格。

“重新测试”按原配置和种子创建新记录，原结果保持不变，相同物理输入可能命中缓存。

## 查看每次测试的参数

顶部“实验参数”显示目标、搜索范围、约束、预算、随机种子与场景快照。每个候选的“查看参数”提供：

| 页面 | 内容 |
|---|---|
| 构型参数 | 机身、电池、载荷、旋翼、控制器，以及运行时合成惯量与实际增益 |
| 评估记录 | L1/L2 状态、版本、指标、约束原因、缓存、执行尝试、耗时与诊断 |
| 测试条件 | 所属实验的场景、种子、搜索空间和预算 |
| 轨迹 | 名义动力学试验的俯视轨迹、时间滑块、位置、高度与四元数 |
| 原始 JSON | 完整精度的构型、请求与执行数据 |

缓存命中不产生新尝试。演示模式、L1 淘汰或未完成 L2 的候选没有动力学轨迹；旧记录缺少的运行参数不会被补写为新试验结果。

## 理解结果与导出

- 最佳续航和最小误差分别取极值，可能来自不同候选。
- 帕累托方案是在已通过方案中未被其他方案同时支配的集合，不等于唯一最优解。
- 轨迹采用 NED，向下为正，页面高度是位置 z 的相反数。
- ANALYTIC 为静态解析，DEMO 为演示，DYNAMICS 为探索级动力学，PENDING 为尚无评估结果；标签不替代通过/失败状态。

“导出报告”下载包含配置、候选、指标和执行记录的 JSON。“导出 DroneIR”下载指定构型与设计哈希。

适用范围见 [模型能力边界](../architecture/overview.md#能力边界)。
